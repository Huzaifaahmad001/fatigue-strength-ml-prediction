# Data-Driven Fatigue Strength Prediction using Machine Learning

## 📌 Project Overview
This project focuses on building machine learning models to predict the fatigue strength of heat-treated 4140 alloy steel using experimental and compositional data. The objective is to demonstrate an end-to-end machine learning workflow applied to a real-world engineering problem.

This work was developed as part of my Final Year Project (FYP) and reflects the application of machine learning techniques to structured engineering datasets.

---

## 🎯 Problem Statement
Fatigue failure is a critical concern in mechanical and automotive components. Traditional experimental fatigue testing is time-consuming and costly. This project aims to predict fatigue strength using machine learning models to enable faster and data-driven material performance assessment.

---

## 📊 Dataset Description
The dataset includes:
- Chemical composition parameters  
- Heat treatment conditions  
- Experimentally measured fatigue strength values  

Preprocessing steps:
- Handling missing values  
- Feature scaling and normalization  
- Correlation analysis and feature selection  

---

## 🧠 Machine Learning Models Used
- Random Forest Regressor  
- Artificial Neural Network (ANN)  

---

## 📈 Model Performance

| Model | R² Score |
|------|----------|
| Random Forest | 0.986 |
| Artificial Neural Network | 0.971 |

---

## 🔍 Key Insights
- Chemical composition and heat treatment parameters significantly influence fatigue strength  
- Feature engineering played a key role in improving model accuracy  
- Machine learning can reduce dependency on extensive experimental testing
